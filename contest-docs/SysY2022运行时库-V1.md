# SysY 运行时库（2022 版）

> 本文由同名 PDF 转写整理。SysY2022 相比 2020 版，在基本类型上增加了 `float` 类型，并支持元素类型为 `float` 的多维数组。

SysY 运行时库提供一系列 I/O 函数、计时函数等，用于在 SysY 程序中表达输入/输出、计时等功能需求。这些库函数不用在 SysY 程序中声明即可在 SysY 的函数中使用。

需要指出的是：部分 SysY 库函数的参数类型会超出 SysY 支持的数据类型，例如字符串。SysY 编译器需要能处理这种情况，将 SysY 程序中这样的参数正确传递给 SysY 运行时库。

## 1. 运行时库的相关文件

大赛组委会提供如下 SysY 运行时库文件给参赛选手：

- `libsysy.a` 和 `libsysy.so`：分别是 SysY 运行时库的静态库和动态库文件（面向大赛目标平台）。后续为公平起见，大赛组委会将统一按静态库链接进行评测。
- `sylib.h`：其中包含 SysY 运行时库涉及的函数等声明。

注：SysY 源程序中不出现对 `sylib.h` 的文件包含，而由 SysY 编译器分析和处理 SysY 程序中对这些函数的调用。

## 2. I/O 函数

SysY 运行时库提供一系列 I/O 函数，支持对整数、浮点数、字符以及一串整数或浮点数的输入和输出。为便于在 SysY 程序中控制输出格式，诸如 `putf` 这样的 I/O 函数会使用超出 SysY 语言支持的数据类型的参数，例如格式字符串。

下面函数中，各个参数为整数值、浮点数、变量、数组元素访问表达式。

### 2.1 `int getint()`

输入一个整数，返回对应的整数值。

示例：

```c
int n;
n = getint();
```

### 2.2 `int getch()`

输入一个字符，返回字符对应的 ASCII 码值。

示例：

```c
int n;
n = getch();
```

### 2.3 `float getfloat()`

输入一个浮点数，返回对应的浮点数值。

示例：

```c
float n;
n = getfloat();
```

### 2.4 `int getarray(int[])`

输入一串整数，第 1 个整数代表后续要输入的整数个数，该个数通过返回值返回；后续整数通过传入的数组参数返回。

注：`getarray` 函数获取传入数组的起始地址，不检查调用者提供的数组是否有足够空间容纳输入的一串整数。

示例：

```c
int a[10][10];
int n;
n = getarray(a[0]);
```

### 2.5 `int getfarray(float[])`

输入一个整数后跟若干个浮点数，第 1 个整数代表后续要输入的浮点数个数，该个数通过返回值返回；后续浮点数通过传入的数组参数返回。

注：`getfarray` 函数获取传入数组的起始地址，不检查调用者提供的数组是否有足够空间容纳输入的一串浮点数。

示例：

```c
float a[10][10];
int n;
n = getfarray(a[0]);
```

### 2.6 `void putint(int)`

输出一个整数的值。

示例：

```c
int n = 10;
putint(n);
putint(10);
putint(n);
```

输出：

```text
101010
```

### 2.7 `void putch(int)`

将整数参数的值作为 ASCII 码，输出该 ASCII 码对应的字符。

注：传入的整数参数取值范围为 0 至 255，`putch()` 不检查参数合法性。

示例：

```c
int n = 10;
putch(n);
```

将输出换行符。

### 2.8 `void putfloat(float)`

输出一个浮点数的值。

示例：

```c
float n = 10.0;
putfloat(n);
putfloat(10.0);
putfloat(n);
```

输出：

```text
10.00000010.0000010.000000
```

注：上述输出为 PDF 原文，第二个 `10.0000010.000000` 的分隔按原文保留。

### 2.9 `void putarray(int, int[])`

第 1 个参数表示要输出的整数个数（假设为 N），后面应该跟上要输出的 N 个整数的数组。`putarray` 在输出时会在整数之间安插空格。

注：`putarray` 函数不检查参数合法性。

示例：

```c
int n = 2;
int a[] = {2, 3};
putarray(n, a);
```

输出：

```text
2:2 3
```

### 2.10 `void putfarray(int, float[])`

第 1 个参数表示要输出的浮点数个数（假设为 N），后面应该跟上要输出的 N 个浮点数的数组。`putfarray` 在输出时会在浮点数之间安插空格。

注：`putfarray` 函数不检查参数合法性。

示例：

```c
int n = 2;
float a[] = {2.0, 3.0};
putfarray(n, a);
```

输出：

```text
2:2.000000 3.000000
```

### 2.11 `void putf(<格式串>, int, ...)`

第 1 个参数为格式字符串，其中仅包含 3 种格式符：`%d`、`%c`、`%f`。该函数将根据格式串进行输出：遇到普通字符则原样输出，遇到格式符 `%d`、`%c` 或 `%f` 则从第 2 个参数起依次取对应参数的值，按整数、字符或浮点数输出。

示例：

```c
int n = 2;
int a[] = {2, 3};
putf("%d: %d(%c), %d(%c)", n, a[0], a[0] + 48, a[1], a[1] + 48);
```

输出：

```text
2:2(2), 3(3)
```

## 3. 计时函数

SysY 运行时库提供 `starttime`、`stoptime` 一对函数，用于对 SysY 中的一段代码运行进行计时。在一个 SysY 程序中，可以插入多对 `starttime`、`stoptime` 调用来获得每对调用之间代码的执行时长，并在 SysY 程序执行结束后得到这些计时的累计执行时长。

需要注意的是：`starttime`、`stoptime` 不支持嵌套调用形式，即不支持 `starttime() ... starttime() ... stoptime() ... stoptime()` 这样的调用执行序列。

### 3.1 `void starttime()`

开启计时器。此函数应和 `stoptime()` 联用。

### 3.2 `void stoptime()`

停止计时器。此函数应和 `starttime()` 联用。程序会在最后结束时，整体输出每个计时器所花费的时间，并统计所有计时器的累计值。

输出格式：

```text
Timer#编号@开启行号-停止行号: 时-分-秒-微秒
```

示例：

```c
void foo(int n) {
    starttime();
    for (int i = 0; i < n; i++) system("sleep 1");
    stoptime();
}

int main() {
    starttime();
    for (int i = 0; i < 3; i++) system("sleep 1");
    stoptime();
    foo(2);
}
```

输出：

```text
Timer#001@0010-0012: 0H-0M-3S-3860us
Timer#002@0005-0007: 0H-0M-2S-2660us
TOTAL: 0H-0M-5S-6520us
```
